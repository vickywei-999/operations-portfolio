# 南京虎虎｜小红书内容策划与复盘

**方向：Social Content · Copywriting · Content Review**

## 背景

品牌在小红书需要将产品信息转化为用户愿意阅读、讨论和收藏的内容。单篇选题还需要与账号整体表达、平台趋势和后续发布衔接，因此工作覆盖内容制作，也包括反馈收集和复盘。

## 本人职责

- 参与品牌小红书账号运营，完成 **17 篇笔记**的选题、撰写、发布与复盘。
- 观察平台热点、竞品内容和用户关注趋势，寻找与产品卖点匹配的表达角度。
- 参与内容审核与质量把控，检查卖点、视觉方向与品牌表达的一致性。
- 整理咨询与评论反馈，将内容表现带入后续选题和发布调整。

## 方法与流程

| 阶段 | 具体工作 |
| --- | --- |
| 选题 | 对照用户关注点、平台趋势和产品卖点，确定笔记要回答的问题 |
| 制作 | 根据内容需要选择种草、测评、清单或攻略等表达形式，完成标题、正文与视觉方向 |
| 发布 | 检查内容质量及品牌表达，完成账号发布与相关互动 |
| 复盘 | 回看标题、封面、卖点和评论反馈，归纳高互动内容的共同特征 |
| 再应用 | 将复盘发现用于后续选题、内容形式与发布安排 |

## 成果与交付

我完成了 **17 篇小红书笔记**的选题、撰写、发布与复盘，内容涉及种草、测评、清单和攻略等形式。

除单篇内容交付外，我还回看标题、封面、卖点与评论反馈，归纳高互动内容的共同特征，并将这些发现用于后续选题和视觉方向。内容审核与用户答疑也让我能够持续核对品牌表达与读者实际关注的问题。
